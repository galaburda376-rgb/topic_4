# Классификация спама и кликбейта в Telegram-сообщениях

Кейс4: «Классификация спама и кликбейта: распознавание спам-сообщений и
кликбейт-заголовков». Задача разработать систему, которая классифицирует
текстовые сообщения из Telegram на два класса: spam (нежелательные
сообщения - это рекламные, мошеннические,автоматические) и clickbait

Репозиторий проекта: https://github.com/galaburda376-rgb/topic_4
Полный отчёт по заданию: [REPORT.md](REPORT.md).

## Структура проекта
data/
  generate_dataset.py генератор синтетического датасета
  dataset.csv            сырой датасет (сообщение, метка, флаги шума)
  dataset_clean.csv      датасет после предобработки (+ колонка clean_text)
  train.csv / val.csv / test.csv — разбиение 70/15/15
  
src/
  preprocessing.py      предобработка текста 
  split_data.py            разбиение на train/val/test 
  train_baseline.py   TF-IDF + логистическая регрессия 
  train_rnn_cnn_ensemble.pyансамбль RNN+CNN с весами по валидации 
  error_analysis.py       анализ ошибок классификации 

results/  метрики, графики, CSV с ошибками
